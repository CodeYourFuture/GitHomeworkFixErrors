## 4. What happens when you `fork` a repository?
Forking a repository creates a personal copy of it in your GitHub account that you can change without affecting the original.


## 5. What happens when you clone a repository?

Cloning a repository creates a local copy of it on your computer so you can view, edit, and work on the code.


## 6. What is a Pull Request?

A pull request is a request to merge your changes into another repository’s main codebase.
