# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

A programming language used to make websites interactive.

## 3. Name three problems Git & GitHub solve?

version control, collaboration, tracking changes, backup of code

## 4. What happens when you `fork` a repository?

You create your own copy of someone else’s repository on GitHub

## 5. What happens when you clone a repository?

It downloads a copy of a repository to your local computer

## 6. What is a Pull Request?

A request to merge your changes into another branch or repository
