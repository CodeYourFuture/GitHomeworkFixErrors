# Linus's Homework

## 1. What is 2 + 2?

4
## 2. What is JavaScript?

JavaScript (JS) is a lightweight interpreted (or 
just-in-time compiled
) programming language with first-class functions.

## 3. Name three problems Git & GitHub solve?

Showcase or share your work.
Track and manage changes to your code over time.
Let others review your code, and make suggestions to improve it

## 4. What happens when you `fork` a repository?

You create a server side copy on your personal account

## 5. What happens when you clone a repository?

It makes a local copy on your device

## 6. What is a Pull Request?

Pull requests are proposals to merge code changes into a project.
