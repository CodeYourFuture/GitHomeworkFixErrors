## 2. What is JavaScript?

JavaScript (JS) is a programming language and core technology of the web platform, alongside HTML and CSS.

## 3. Name three problems Git & GitHub solve?

Git and GitHub have become indispensable tools for software development, enabling collaboration, version control, and streamlined workflows.

## 4. What happens when you `fork` a repository?

Forking a repository means you can make any changes you want to the code without affecting the original project. You can choose to share those changes with the original repo through the pull request process.

## 5. What happens when you clone a repository?

When you clone a repository, you download a complete copy of the project and its entire version history from a remote server (like GitHub) to your local machine, creating a new, disconnected copy of the project that also contains a link back to the original server

## 6. What is a Pull Request?

A pull request is a formal proposal for a developer to merge their code changes from a separate branch into a target branch, such as a main or master branch, in a project's repository.
