# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

A programming language used to make websites interactive.

## 3. Name three problems Git & GitHub solve?

1. Tracking changes in code over time
2. Collaboration with other developers
3. Backing up code safely in the cloud

## 4. What happens when you fork a repository?

You copy it to your own GitHub account.

## 5. What happens when you clone a repository?

You download a copy of the repository to your local computer.

## 6. What is a Pull Request?

A request to merge your code changes into another branch.
