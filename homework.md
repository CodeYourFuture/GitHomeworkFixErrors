## 3. Name three problems Git & GitHub solve?

People can store their code online so just in case the local file corrupts then you have an online version. People can showcase their code to others so employers can see what they are capable of doing. People can also work collaboratively on a project as well.

## 4. What happens when you `fork` a repository?

You create your own copy of the repository that you can work on.

## 5. What happens when you clone a repository?

You copy a repository onto your local drive.
