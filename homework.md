## 3. Name three problems Git & GitHub solve?

Allows multiple people to work on the same project remotely. Allows you track when changes are made, see who made those changes and see what does changes are. Github also allows you to save a copy of your work in a virtual environment that allows you to access your work from any device. 

## 4. What happens when you `fork` a repository?

You make a copy of that repo, allowing you to make changes without it changing the other person's original repo.

## 5. What happens when you clone a repository?

Clone a repo is saving it to your local P.C in order to be able to work on it from there.

## 6. What is a Pull Request?

A pull request is basically a merge request, where you request to merge your changes to the main repository
