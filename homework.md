# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

JavaScript is a programming language.

## 3. Name three problems Git & GitHub solve?

GitHub allows multiple developers to work on the same project at the same time. Git is a version control software that allows developers to create and manage different versions of a project, avoiding any duplication of work.

## 4. What happens when you `fork` a repository?

You create a copy of the repository on GitHub.

## 5. What happens when you clone a repository?

A local copy of the repository is copied onto a local machine.

## 6. What is a Pull Request?

A pull request is a way to share your code for review.
