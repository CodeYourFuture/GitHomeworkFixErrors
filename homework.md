## 2. What is JavaScript?

## 3. Name three problems Git & GitHub solve?

Version control — Git keeps track of every change you make to your files so you can go back to earlier versions if something breaks.

Collaboration — GitHub allows many people to work on the same project at the same time without overwriting each other’s work.

Backup and remote storage — GitHub stores your code online so it’s safe if your computer is lost or damaged.

## 4. What happens when you `fork` a repository?

When i 'fork' a repository I create my own copy of someone else’s project on my GitHub account, so I can edit it without affecting the original.

## 5. What happens when you clone a repository?

When I clone a repository, I download a full copy of the project from GitHub onto my computer so I can work on it locally in VS Code.

## 6. What is a Pull Request?

A Pull Request (PR) is a request to merge your changes from your branch into another repository or branch. It’s how you ask the project owner to review your work before it becomes part of the main project.
