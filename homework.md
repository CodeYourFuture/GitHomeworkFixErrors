## 2. What is JavaScript?

A programming language mainly used for the web, as it can interact with both HTML and CSS

## 3. Name three problems Git & GitHub solve?

Always know what the most recent version of the code is and let's you keep track of all previous versions and when they were created.
Branches let people work on different parts of the code at the same time, without interfeering with each other.
With Github, the code is saved online so it can be accessed on different machines.

## 4. What happens when you `fork` a repository?

Creates a copy of somebody elses repository in your own Github.

## 5. What happens when you clone a repository?

Creates a copy of a repository in your local machine, allowing you to work on the code using an IDE like VSCode.

## 6. What is a Pull Request?

A Git command that allows you to upload your local changes to the Github repository. Before using it, all changes need to be committed.
