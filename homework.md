# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

An exciting programming language used for wed pages, applications, automation and game development.

## 3. Name three problems Git & GitHub solve?

Tracks alterations and all previous versions of code
Allows collaboration on the same document across different devices/ accounts
Stores code in the cloud to reduce loss of work

## 4. What happens when you `fork` a repository?

Creates an alternate version under your own username that is editable without affecting the original main branch.

## 5. What happens when you clone a repository?

It makes a local copy onto your device

## 6. What is a Pull Request?

When you request your locally edited code to be merged into the original repository so changes can be reviewed which is especially important before becoming part of a project.
