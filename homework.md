## 1. What is 2 + 2?

## 2. What is JavaScript?

A JavaScript is a programming language used to add interactivity and behaviour to websites. It can also run outside a web browser.

## 3. Name three problems Git & GitHub solve?

Tracking changes to files and returning to earlier versions.
Helping people collaborate on the same project and combine their changes.
Hosting repositories online so people can share and access their code.

## 4. What happens when you `fork` a repository?

You create your own copy of a repository on GitHub. You can make changes to your copy without affecting the original repository.

## 5. What happens when you clone a repository?

You download a local copy of a repository, including its Git history, to your computer.

## 6. What is a Pull Request?

A pull request is a proposal to merge changes from one branch into another. It allows people to review and discuss the changes before merging them.
