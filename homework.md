## 3. Name three problems Git & GitHub solve?

It solves the problem of version control, streamlined workflow and effective collaboration

## 4. What happens when you `fork` a repository?

You create an independent and complete copy of it in your own account

## 5. What happens when you clone a repository?

It creates a complete copy of it on your conmputer, giving you local access, so you can edit it and contribute to it offline. 

## 6. What is a Pull Request?

It is a way to propose changes to a code base, and acts as a collaboration hub for reviewing and approving a code before it is accepted on a project.
