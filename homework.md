# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

A programming language used to make web pages interactive

## 3. Name three problems Git & GitHub solve?

Version control - keeps track of changes to code over time
Collaboration - allows multiple people to work on the same project
Backup - stores your code safely online so it's not lost

## 4. What happens when you `fork` a repository?

You create your own copy of someone else's repository on your GitHub account

## 5. What happens when you clone a repository?

You download the repository to your computer so you can work on it locally

## 6. What is a Pull Request?

It is when you ask the repository owner to review and merge your changes into their project
