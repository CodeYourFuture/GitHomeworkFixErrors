# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

JavaScript is a programming language.

## 3. Name three problems Git & GitHub solve?

- Tracking changes to code over time  
- Allowing multiple people to work on the same project  
- Making it easy to share and review code

## 4. What happens when you `fork` a repository?

You create your own copy of the repository on your GitHub account.

## 5. What happens when you clone a repository?

You download a copy of the repository to your computer.

## 6. What is a Pull Request?

A Pull Request is a request to merge your changes into another repository.
