## 1. What is 2 + 2?

## 2. What is JavaScript?

JavaScript is a programming language used mainly to make web pages interactive and dynamic.

## 3. Name three problems Git & GitHub solve?

Version control – Track changes to code over time.

Collaboration – Let multiple people work on the same project safely.

Backup & sharing – Store code remotely and share it easily.

## 4. What happens when you `fork` a repository?

The target repository will be copied to another new space in my own account.

## 5. What happens when you clone a repository?

You download a full copy of the repository (all files, history, and branches) from GitHub (or any remote) to your local machine.

## 6. What is a Pull Request?

A Pull Request is a request to merge your changes from one branch (often your fork) into another branch of a repository, usually after review.
