# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

JavaScript is a language that tells websites how to move, change, and do fun things.

## 3. What three problems does Git & GitHub solve?

Saving: Git/GitHub keep safe copies of your code.

Sharing: They let you share code with friends or teammates.

Tracking: They remember every change so you can go back if something breaks.

## 4. What happens when you `fork` a repository?

When you fork a repository, it’s like making your own copy of someone else’s toy so you can play and change it without breaking theirs.

## 5. What happens when you clone a repository?

When you clone a repository, it’s like bringing a copy of the toy from the store to your home so you can play with it on your own computer.

## 6. What is a Pull Request?

A pull request is like asking the toy’s owner, “Can I add my changes to your toy?” so they can check and say yes or no.
