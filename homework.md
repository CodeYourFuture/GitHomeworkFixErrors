# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

A programming language that brings interactivity to static web pages, applications and more.

## 3. Name three problems Git & GitHub solve?

Showcase or share your work.
Track and manage changes to your code over time.
Let others review your code, and make suggestions to improve it.

## 4. What happens when you `fork` a repository?

It creates a personal, server-side copy of another user's project under your own account.

## 5. What happens when you clone a repository?

Git creates a full, identical local copy of the remote repository on your computer.

## 6. What is a Pull Request?

A user-initiated proposal to merge a set of code changes from one branch or fork into another repository branch.
