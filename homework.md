## 3. Name three problems Git & GitHub solve?

- Keeps a record of all the changes that have been made to a project which means if an update breaks something within a project or we want to go back to a previous version, it can be reverted easily.

- Allows multiple people to work on the same project without getting confused as we can use branches to make experimental changes to existing projects without affecting the main branch.

- Git and Github allow for streamlined workflows as people can work on the same project simultaneously and use personal branches to make changes before they are approved for the main branch.

## 4. What happens when you `fork` a repository?

You get a copy of that repository added to your personal GitHub account.

## 5. What happens when you clone a repository?

You get a local copy of all the files in the project on your personal computer.

## 6. What is a Pull Request?

A proposal to merge a set of changes from one branch of a project to the main branch which allows for code review and discussion before it is approved
