## 3. Name three problems Git & GitHub solve?

1. A team can worktogether on a project in a remote version control platform
2. Allow to track who made changes, and when.
3. One can publish a website on Github.

## 4. What happens when you `fork` a repository?

It allows me to have a version of it on my Github and work on it independently without affecting the main branch.

## 5. What happens when you clone a repository?

It allows you to have it in your local computer and work on it there instead of a remote version control.

## 6. What is a Pull Request?

It allows to receive feedback from others in your work, and it your work been accepted it can move to the main branch.
