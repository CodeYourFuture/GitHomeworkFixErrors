## 2. What is JavaScript?

## 3. Name three problems Git & GitHub solve?

-Version control
-Collaboration
-Backup and distribution

## 4. What happens when you `fork` a repository?

Forking creates your own copy of someone else’s repository on your GitHub account

## 5. What happens when you clone a repository?

Cloning downloads a repository (either yours or someone else’s) from GitHub to your local machine

## 6. What is a Pull Request?

A Pull Request is a request to merge your changes (from your branch or fork) into another branch or repository
