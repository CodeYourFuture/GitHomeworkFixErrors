## 3. Name three problems Git & GitHub solve?

Using Git and Github allows multiple poeple to work on the same file, simultenously even, without overriding eah other's work. It keeps track of changes and these changes can be reviewed before making final changes. 

## 4. What happens when you `fork` a repository?

You create a copy of someone else's repo, but it keeps it linked to the original. 

## 5. What happens when you clone a repository?

You download it from Github to your local computer.

## 6. What is a Pull Request?

A pull request is essentially a call for a review. When you finish making adjustments, you want to merge it to the main branch, you send this request for a review. this will then be reviewed and either merged or rejected in whcih case further adjustments will need to be made.
