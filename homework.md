# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

A coding language for web applications

## 3. Name three problems Git & GitHub solve?

1. Keeping track of several current versions of a project
2. Accessing old versions of a project
3. Working collaboratively

## 4. What happens when you `fork` a repository?

You create your own version of a project to work on without affecting the original version (unless you create pull requests)

## 5. What happens when you clone a repository?

You create another version of it locally on your own computer so you can work in your own IDE and push the updates to github

## 6. What is a Pull Request?

When you request that one of your own updates to the code get merged back into the main original version of the project.
