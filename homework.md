## 3. Name three problems Git & GitHub solve?

Version Control and History Management: Git solves the problem of losing code or being unable to undo mistakes.
Collaborative Bottlenecks: Without these tools, multiple people editing the same file often overwrite each other's work. 
Project Transparency and Organization: GitHub provides a central platform for project management that Git alone does not have.
