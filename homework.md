## 2. What is JavaScript?

## 3. Name three problems Git & GitHub solve?

Git & Github allow people to showcase or share their work, to track and manage changes to their code over time, and to let others review their code and make suggestions to improve it.

## 4. What happens when you `fork` a repository?

You create a personal, server-side copy of another user's project under your own account. 

## 5. What happens when you clone a repository?

You copy the repository from GitHub.com to your local machine

## 6. What is a Pull Request?

A pull request is a method in version control systems (like GitHub, Bitbucket, or GitLab) where a developer notifies team members that they have completed a feature or bug fix in a separate branch. It acts as a formal proposal to merge these new code changes into the main codebase.
