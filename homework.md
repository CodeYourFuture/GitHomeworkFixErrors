## 3. Name three problems Git & GitHub solve?

## 4. What happens when you `fork` a repository?

It makes copy of someone's repo to your own github account.

## 5. What happens when you clone a repository?

It makes copy of repo on local machine. You make make changes on you local machine and then push to github repo.
