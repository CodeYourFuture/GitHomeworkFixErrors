## 3. Name three problems Git & GitHub solve?

Collaboration, version control, and streamlined workflows.

## 4. What happens when you `fork` a repository?

You will copy the repository to your own account, which allows you making changes to the code without affecting the original project. Forking allows collaboration development, and contributing back to the original with pull requests. 

## 5. What happens when you clone a repository?

You copy the repository from github to your local machine. 

## 6. What is a Pull Request?

A pull request is a formal proposal in a git based version control system, to merge changes from a branch into the main, allowing team members to review the changes, discuss them, provide feedback, and approve the integration into the project.
