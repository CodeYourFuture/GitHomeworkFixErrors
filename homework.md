## 2. What is JavaScript?

It's a programming language used to make webpages interactive.

## 3. Name three problems Git & GitHub solve?

-They help programmers work in the same project at the same time without overwriting one another's work.
-They store several versions of a project and save a lot of time and integrity.
-They save a lot of mistakes that may cause the main project a lot of issues.

## 4. What happens when you `fork` a repository?

When you fork a repo, the project you've forked is copied onto your GitHub account and makes it your personal copy on which you can work on without worrying causing any troubles.

## 5. What happens when you clone a repository?

You download the repository to your personal machine so you can work on it locally.

## 6. What is a Pull Request?

It is a request made to merge your commit changes onto the main branch or the original repository.
