## 3. Name three problems Git & GitHub solve?

Collaboration: They enable developers to work together on projects, sharing their work and allowing others to make changes.
Version Tracking: They keep track of all changes made to a project, allowing developers to revert to older versions if needed.
Error Resolution: They provide methods to undo mistakes, revert changes, and resolve merge conflicts, ensuring a smooth development process.
