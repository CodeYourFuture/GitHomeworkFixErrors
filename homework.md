# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

JavaScript is an interactive and dynamic web pages created by high level programming language.

## 3. Name three problems Git & GitHub solve?

1. Changes being overwritten
2. Conflicts arising from collaboration
3. There is no single source of truth

## 4. What happens when you `fork` a repository?

You create your own copy of the repository to make changes and push back to the main repository

## 5. What happens when you clone a repository?

You have your own copy of the repository but changes will not reflect on the main repository.

## 6. What is a Pull Request?

When you merge changes you have made in your own branch to the main branch.
