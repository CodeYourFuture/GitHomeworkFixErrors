# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

A coding language.

## 3. Name three problems Git & GitHub solve?

Difficulty sharing code between local machines
Difficulty keeping multiple revisions of old code
Difficulty for multiple users to work on same code base simultaneously


## 4. What happens when you `fork` a repository?

You create a copy on your own git account.

## 5. What happens when you clone a repository?

You create a copy on a local machine.

## 6. What is a Pull Request?

It is a request to merge changes to the main codebase.
