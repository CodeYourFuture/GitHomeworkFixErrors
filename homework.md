## 3. Name three problems Git & GitHub solve?

It allows people to work on the same project and share their progress without disturbing someone else's work.
It provides the history of the changes made to the project in a structured manner.
It helps in maintaining different versions of your work or software.

## 4. What happens when you `fork` a repository?

You copy that repository inside your repositories.

## 5. What happens when you clone a repository?

It is cloned on your local machine.

## 6. What is a Pull Request?

It is a request created for others to pull your repository and review it if they want.
