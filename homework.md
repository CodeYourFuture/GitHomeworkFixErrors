## 3. Name three problems Git & GitHub solve?

1. Git and GitHub provides a platform that makes it easier for software developers to collaborate on projects

2. Git and Git hub make it easier for you to share and deploy your code and documentation by hosting repos online

3. Git helps to implement an effective strategy for version control. It tracks all the changes you make to your projects; allows you to safely go back to previous versions and shows who changed what and when.

## 4. What happens when you `fork` a repository?

forking creates your own independent copy of a project. Forking give you the ability to experiment, make changes and contribute to that project without affecting the original repository.

## 5. What happens when you clone a repository?

When cloning you create a local copy of the project.

## 6. What is a Pull Request?

This is how you submit your proposed changes to the owner of the original repo for review.
