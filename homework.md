## 3. Name three problems Git & GitHub solve?

Backs up your work, allows different people to work on the same project regardless of the distanse or time, and allows individuals to create a portfolio for future employment. 

## 4. What happens when you `fork` a repository?

You create your own coppy of someone else's project.

## 5. What happens when you clone a repository?

You create a local copy of a project to work in your own computer.

## 6. What is a Pull Request?

Sending your changes and improvements of a project to the original author for review.
