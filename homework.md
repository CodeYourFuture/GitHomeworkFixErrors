## 2. What is JavaScript?

A programming language.

## 3. Name three problems Git & GitHub solve?

Git and GitHub help stop work being lost make it easier to work with other people, and avoid confusing file versions.

## 4. What happens when you `fork` a repository?

When you fork a repository on GitHub you create your own copy of a project that you can edit without changing the original.

## 5. What happens when you clone a repository?

Cloning a repository means downloading a copy of a project on to your computer.

## 6. What is a Pull Request?

A pull request is when you ask someone to check your changes and add them to the main project.
