## 4. What happens when you `fork` a repository?

When you fork a repository on GitHub, you create your own independent copy of someone else's repository under your GitHub account that enables us Creates a Complete Copy, Maintains Connection and Full Control

## 5. What happens when you clone a repository?

When you clone a Git repository, a complete, self-contained copy of the remote project's files, history, and metadata is downloaded to your local machine, creating a new local repository that is linked to the original remote. This new local copy includes all commits, branches, and tags, allowing you to work offline on the project and later synchronize your changes with the remote repository. 

## 6. What is a Pull Request?

A Pull Request is a proposal to merge your changes into the main repository. It allows code review and discussion before the changes are accepted.
